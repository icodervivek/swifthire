# SwiftHire 🚀

**SwiftHire makes hiring easy!**  
Need help with a task? Find skilled workers in just a few clicks. From tech to trades, we’ve got the pros you need — ready to work when you are.

---

## 🛠 Features

- **Find Skilled Workers:** Quickly search for professionals across various domains.  
- **Easy Hiring:** Connect with workers instantly without long onboarding.  
- **Responsive UI:** Clean, modern design for seamless experience on all devices.  
- **Authentication:** Secure signup/login system.  
- **Contact Form:** Reach out directly to the team for queries or support.  

---

## 💻 Tech Stack

| Layer        | Technology |
| ------------ | ---------- |
| Frontend     | React, Tailwind CSS |
| Backend      | Node.js, Express.js |
| Database     | Neon (PostgreSQL) |
| API          | RESTful APIs with JWT authentication |

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/icodervivek/swifthire.git
cd swifthire
```

### 2. Install dependencies

#### Backend
```bash
cd server
npm install
```

#### Frontend
```bash
cd client
npm install
```

### 3. Set up environment variables
Create a `.env` file in the backend:
```env
PORT=3000
DATABASE_URL=your_neon_db_url
JWT_SECRET=your_secret_key
```

### 4. Run the application

#### Backend
```bash
cd server
npm run dev
```

#### Frontend
```bash
cd client
npm run dev
```

Open your browser at `http://localhost:5173` to see the app.
